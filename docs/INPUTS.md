# Input data

Paths beginning with `Data/`, `metadata/` or `Adata_Saves/` are relative to `CAP_PROJECT`. Paths beginning with `data/` are relative to this release directory. Protein input paths are relative to `CAP_PROTEOME`.

## Single-cell counts and metadata

Source: GSE161529, the breast atlas described by Pal et al. (2021). The workflow starts from deposited filtered count matrices rather than sequence reads.

| Input | Expected location |
|---|---|
| Per-library count matrices | `$CAP_RAW_DATA/<sample_id>-matrix.mtx.gz` |
| Per-library barcodes | `$CAP_RAW_DATA/<sample_id>-barcodes.tsv.gz` |
| Shared feature table | `$CAP_RAW_DATA/../features.tsv` |
| Cohort metadata | `metadata/samples.csv`, generated by 000 |

Matrices are read as genes × cells and transposed for AnnData. Notebook 000 inventories 69 source libraries and records inclusion decisions for 45 libraries from 42 patients. Included groups comprise 13 normal, 8 TN, 6 HER2+ and 18 ER+ libraries. Male, BRCA1-preneoplastic, lymph-node and epithelially sorted libraries are excluded; BRCA1-mutant primary tumours remain included.

Only filtered matrices are used. Empty-droplet counts and read-level information are not inputs to this workflow.

## Annotations and signatures

| Input | Expected location | Use |
|---|---|---|
| GENCODE v50 | `Data/gencode.v50.annotation.gtf.gz` | Ensembl-ID-based CNV gene coordinates |
| CellTypist reference | `Data/model_from_pal.pkl` | Supporting whole-atlas annotation |
| Cancer meta-programme workbook | `data/cancer_meta_programme_signatures.xlsx` | Frozen programme definitions |
| Source cluster barcodes | `data/source_tumour_cluster_barcodes.csv.gz` | Supporting source-cluster concordance |
| Transfer exclusions | `data/source_transfer_exclusions.csv` | Sample-identity exclusions |

Frozen-workbook and barcode checksums and their source identifiers are documented [with the files](../data/README.md). The source-cluster table is read by 003a but is not the primary definition of tumour-derived epithelium.

The CellTypist model's training/reference composition and redistribution provenance are not specified by its filename. Record those details with any public deposition.

## Protein cohorts

Set `CAP_PROTEOME` to the directory holding `Lee_MOESM2_ESM.xlsx` and its `data/`, `cache/` and `output/` subdirectories. Without an override, the loader checks `Data/proteomics/` under `CAP_PROJECT`, then the existing local `bulk/` sibling used by the development project. These are external data locations, not required code-directory names.

| Input | Expected location |
|---|---|
| Kosok protein matrix | `$CAP_PROTEOME/data/mmc2.xlsx` |
| Lee protein matrix | `$CAP_PROTEOME/Lee_MOESM2_ESM.xlsx` |
| Lee subtype metadata | `$CAP_PROTEOME/data/Lehmann.csv` |
| Lee protein-to-gene mapping | `$CAP_PROTEOME/cache/lee_uniprot_gene_mapping.csv` |
| Anurag protein matrix | `$CAP_PROTEOME/data/cd-22-0200_table_s3_suppst3.xlsx` |
| Anurag specimen metadata | `$CAP_PROTEOME/data/cd-22-0200_table_s1_suppst1.xlsx` |
| Hallmark signatures | `$CAP_PROTEOME/data/h.all.v2026.1.Hs.symbols.gmt` |

Source studies are Kosok et al. (2020; PXD017025), Lee et al. (2026; PDC000695) and Anurag et al. (2022; PDC000408). The primary Anurag set is restricted to baseline specimens.

`Three_Proteome.ipynb` validates input presence and writes file sizes and SHA-256 checksums to `$CAP_PROTEOME/output/three_proteome_input_provenance.csv`. Signature coverage, specimen counts and effective association sample sizes are recorded in its output tables. A separate MALTA signature is not required.

## Normal-tissue protein reference

| Input | Expected location |
|---|---|
| Cached HPA DVP archive | `Data/dvp_cell_type_group_data.tsv.zip` |

The archive contains the cell-type-group intensity table distributed by HPA. Notebook 003d reads the cached file and records its checksum, source URL, formula and missing-data convention in `Dataframe_Saves/hpa_dvp_input_provenance.json`.

The current archive does not encode its HPA release or retrieval date; these metadata remain unresolved. The analysis covers 24 cell-type groups from one donor and contains no breast tissue. Missing measurements remain unquantified in the abundance table.

## Processed objects

Derived H5ADs, scVI models and large figure exports are not installed with the software environment. Their expected filenames and dependencies are listed in the [workflow README](../README.md). Public deposition URLs for the processed objects have not yet been recorded in this repository.

Third-party datasets and signatures retain their original access and reuse conditions. A code license does not determine their redistribution rights.
